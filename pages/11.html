Seletores
CSS / XPath

Como utilizar seletores CSS e XPath para localizar elementos durante os testes. Esses seletores oferecem flexibilidade adicional quando os locators semânticos não atendem ao cenário.

CONCEITO / 11 SELECTORS / CSS / XPATH

Seletores CSS / XPath

CSS Selector / XPath
Selecionar por ID 
await page.locator('#login').click();
Selecionar por classe 
await page.locator('.btn-primary').click();
Selecionar por atributo 
await page
.locator('input[name="email"]')
.fill('teste@email.com');
Selecionar filho direto 
await page.locator('.menu > li').click();
Selecionar elemento descendente 
await page
.locator('.form input')
.fill('João');
Combinar seletores CSS 
await page
.locator('form.login input[name="email"]')
.fill('teste@email.com');
XPath básico 
await page
.locator('xpath=//button')
.click();
XPath por texto 
await page
.locator('xpath=//button[normalize-space()="Enviar"]')
.click();
XPath por atributo 
await page
.locator('xpath=//input[@name="email"]')
.fill('teste@email.com');
XPath com relação entre elementos 
await page
.locator('xpath=//div[@class="form"]//input')
.fill('João');
XPath com texto parcial 
await page
.locator('xpath=//button[contains(normalize-space(), "Enviar")]')
.click();
Exemplo prático 
import { test, expect } from '@playwright/test';

test('usar seletores CSS', async ({ page }) => {

await page.goto('https://example.com');

await page
    .locator('input[name="email"]')
    .fill('user@example.com');

await page
    .locator('input[name="password"]')
    .fill('123456');

await page
    .locator('button[type="submit"]')
    .click();

await expect(
    page.locator('.success-message')
).toBeVisible();

});
Exemplo com XPath 
import { test, expect } from '@playwright/test';

test('usar XPath', async ({ page }) => {

await page.goto('https://example.com');

await page
    .locator('xpath=//input[@name="email"]')
    .fill('user@example.com');

await page
    .locator('xpath=//button[normalize-space()="Entrar"]')
    .click();

await expect(
    page.locator('xpath=//div[contains(@class, "success")]')
).toBeVisible();

});
QA Note

Prefira locators baseados em comportamento e acessibilidade, como getByRole, getByLabel, getByText e getByTestId. Use seletores CSS ou XPath quando forem necessários para localizar elementos que não possuem uma identificação semântica adequada. Evite seletores excessivamente frágeis e dependentes da estrutura interna da página.
