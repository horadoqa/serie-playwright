QA Note

CSS e XPath são mecanismos de seleção utilizados pelo locator() para identificar elementos na página. Sempre que possível, prefira locators baseados em comportamento e acessibilidade, como getByRole(), getByLabel() e getByText(). CSS e XPath são úteis quando esses locators não são suficientes para o cenário.

Exemplo prático com CSS 
import { test, expect } from '@playwright/test';

test('usar seletores CSS', async ({ page }) => {

await page.goto('https://example.com');

await page
    .locator('input[name="email"]')
    .fill('user@example.com');

await page
    .locator('input[name="password"]')
    .fill('123456');

await page
    .locator('button[type="submit"]')
    .click();

await expect(
    page.locator('.success-message')
).toBeVisible();

});
Exemplo prático com XPath 
import { test, expect } from '@playwright/test';

test('usar XPath', async ({ page }) => {

await page.goto('https://example.com');

await page
    .locator(
        'xpath=//input[@name="email"]'
    )
    .fill('user@example.com');

await page
    .locator(
        'xpath=//button[normalize-space()="Entrar"]'
    )
    .click();

await expect(
    page.locator(
        'xpath=//div[contains(@class, "success")]'
    )
).toBeVisible();

});

Boas práticas 
// Prefira locators semânticos

await page
.getByRole('button', {
name: 'Entrar'
})
.click();

// Use CSS quando houver um seletor estável

await page
.locator('[data-testid="login-button"]')
.click();

// Use XPath quando a relação entre elementos
// exigir uma expressão mais específica

await page
.locator(
'xpath=//div[@class="form"]//input'
)
.fill('João');
Evitar seletores frágeis 
// Evite depender de classes geradas

await page
.locator('.css-1a2b3c')
.click();

// Prefira atributos estáveis

await page
.locator('[data-testid="login-button"]')
.click();
QA Note

Prefira locators baseados em comportamento e acessibilidade, como getByRole(), getByLabel(), getByText() e getByTestId(). Use seletores CSS ou XPath quando forem necessários para localizar elementos que não possuem uma identificação semântica adequada. Evite seletores excessivamente frágeis, como classes geradas automaticamente ou caminhos XPath dependentes de muitos níveis da estrutura do DOM.
