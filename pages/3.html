CONCEITO / 03 NAVIGATION

Navegação

Page / Navigation Commands 
await page.goto('https://example.com');

await page.goBack();

await page.goForward();

await page.reload();
QA Note

O objeto page representa uma página do navegador. Através dele, podemos controlar a navegação e aguardar estados importantes da aplicação durante o teste.

Principais comandos
Comando Função
page.goto() Navega para uma URL específica.
page.goBack() Retorna para a página anterior no histórico do navegador.
page.goForward() Avança para a próxima página disponível no histórico do navegador.
page.reload() Recarrega a página atual.
page.waitForURL() Aguarda a página navegar para uma URL que corresponda ao padrão informado.
page.waitForLoadState() Aguarda um estado específico de carregamento da página, como load, domcontentloaded ou networkidle.
goto() 
await page.goto('https://example.com');

await page.goto('https://example.com/login');

await page.goto('https://example.com/dashboard');
goBack() 
await page.goto('https://example.com');

await page.goto('https://example.com/login');

await page.goBack();
goForward() 
await page.goto('https://example.com');

await page.goto('https://example.com/login');

await page.goBack();

await page.goForward();
reload() 
await page.goto('https://example.com');

await page.reload();
waitForURL() 
await page.getByRole('button', {
name: 'Login'

}).click();

await page.waitForURL('**/dashboard');
waitForLoadState() 
await page.goto('https://example.com');

await page.waitForLoadState('domcontentloaded');

await page.waitForLoadState('load');
Validar a URL 
await expect(page)
.toHaveURL(/dashboard/);
Exemplo completo 
import { test, expect } from '@playwright/test';

test('navegação para dashboard', async ({ page }) => {

// Acessa a aplicação
await page.goto('https://example.com');

// Executa uma ação que provoca navegação
await page.getByRole('link', {
    name: 'Dashboard'
}).click();

// Aguarda a URL esperada
await page.waitForURL('**/dashboard');

// Valida a URL
await expect(page)
    .toHaveURL(/dashboard/);

});
QA Note

Quando uma ação provoca uma navegação, prefira aguardar uma condição observável, como waitForURL(), e validar o resultado com expect(). Evite utilizar esperas fixas como waitForTimeout() para sincronizar a navegação.
