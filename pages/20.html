Navegação

Os comandos de navegação permitem acessar páginas, aguardar mudanças de URL e esperar estados específicos de carregamento. 

await page.goto('https://example.com');

await page.waitForURL('**/dashboard');

await page.waitForLoadState('networkidle');

Locators

Locators representam elementos da página e permitem realizar ações e assertions de maneira mais confiável. Dê preferência a locators semânticos quando disponíveis. 

page.getByRole('button', {

name: 'Login'
});

page.getByText('Entrar');

page.getByLabel('E-mail');

page.getByTestId('login-button');

page.locator('#email');

Ações

As ações permitem interagir com a aplicação realizando cliques, preenchimento de campos, seleção de opções, comandos de teclado e upload de arquivos. 

await page.getByRole('button', {

name: 'Login'
}).click();

await page.getByLabel('Nome').fill('João');

await page.getByLabel('Senha').press('Enter');

await page.getByRole('checkbox').check();

await page.getByRole('checkbox').uncheck();

await page.getByLabel('Estado').selectOption('SP');

await page.getByLabel('Arquivo').setInputFiles('arquivo.pdf');

Esperas

O Playwright possui mecanismos de auto-waiting e assertions que aguardam automaticamente as condições necessárias. Em cenários específicos, também é possível aguardar URL ou estados de carregamento. 

await page.waitForURL('**/dashboard');

await page.waitForLoadState('networkidle');

await expect(
page.getByRole('heading', {
name: 'Dashboard'
})
).toBeVisible();

Assertions

As assertions verificam se o comportamento observado corresponde ao resultado esperado pelo teste. 

await expect(page)

.toHaveTitle('Example');

await expect(page)
.toHaveURL(/dashboard/);

await expect(
page.getByRole('button')
).toBeVisible();

await expect(
page.getByRole('button')
).toBeEnabled();

await expect(
page.getByRole('button')
).toBeDisabled();

await expect(
page.getByText('Sucesso')
).toHaveText('Sucesso');

await expect(
page.locator('.item')
).toHaveCount(3);

Validar conteúdo

Além de verificar visibilidade e estado dos elementos, também é possível validar textos, valores, atributos e outras propriedades da interface. 

await expect(

page.getByRole('heading')
).toHaveText('Dashboard');

await expect(
page.getByLabel('E-mail')
).toHaveValue('user@example.com');

await expect(
page.getByRole('button')
).toHaveAttribute(
'type',
'submit'
);

Debug e evidências

Durante a investigação de uma falha, screenshots e pausas podem ajudar a entender o estado da aplicação no momento do problema. 

await page.screenshot({

path: 'example.png'
});

await page.pause();

Capturar screenshot

Screenshots podem ser utilizados como evidência visual da execução do teste. 

await page.screenshot({

path: 'evidencias/dashboard.png',
fullPage: true
});

Exemplo completo

Um fluxo simples combinando navegação, localização, interação, validação e captura de evidência. 

import { test, expect } from '@playwright/test';

test('fluxo básico', async ({ page }) => {

// Navegação
await page.goto('https://example.com');

// Localização
const titulo = page.getByRole('heading', {
name: 'Example Domain'
});

// Validação
await expect(titulo).toBeVisible();

// Evidência
await page.screenshot({
path: 'example.png'
});

});

QA Note

Para memorizar os comandos, pense no fluxo: navegar → localizar → interagir → aguardar → validar . O Playwright possui auto-waiting para diversas ações e assertions. Por isso, evite adicionar esperas artificiais quando uma ação ou assertion já consegue aguardar a condição necessária. Use locators semânticos sempre que possível e mantenha as assertions próximas da ação que está sendo validada. Para investigação de falhas, utilize recursos como page.pause(), screenshot, Trace e os recursos de debug do Playwright.
