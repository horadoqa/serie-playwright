Playwright / Quick Reference

Navegação

Comandos utilizados para navegar entre páginas e acompanhar mudanças de URL ou estados de carregamento. 

page.goto('https://example.com');

await page.waitForURL('**/dashboard');

await page.waitForLoadState('networkidle');

Locators

Os locators permitem encontrar elementos de forma semântica e realizar interações com eles durante os testes. 

page.getByRole('button', {
  name: 'Login'
});

page.getByText('Entrar');

page.getByLabel('E-mail');

page.getByTestId('login-button');

page.locator('#email');

Ações

Comandos utilizados para interagir com os elementos da aplicação, como clicar, preencher campos, selecionar opções e fazer upload. 

await page.getByRole('button').click();

await page.getByLabel('Nome').fill('João');

await page.getByLabel('Senha').press('Enter');

await page.getByRole('checkbox').check();

await page.getByRole('checkbox').uncheck();

await page.getByLabel('Estado').selectOption('SP');

await page.getByLabel('Arquivo').setInputFiles('arquivo.pdf');

Assertions

As assertions verificam se o comportamento observado corresponde ao resultado esperado pelo teste. 

await expect(page).toHaveTitle('Example');

await expect(page).toHaveURL(/dashboard/);

await expect(page.getByRole('button')).toBeVisible();

await expect(page.getByRole('button')).toBeEnabled();

await expect(page.getByRole('button')).toBeDisabled();

await expect(page.getByText('Sucesso')).toHaveText('Sucesso');

await expect(page.locator('.item')).toHaveCount(3);

Debug e evidências

Comandos úteis para investigar falhas, inspecionar a execução e registrar evidências durante os testes. 

await page.screenshot({
  path: 'example.png'
});

await page.pause();

Exemplo de utilização

Um fluxo simples combinando navegação, localização, validação e captura de evidência. 

import { test, expect } from '@playwright/test';

test('fluxo básico', async ({ page }) => {

  // Navegação
  await page.goto('https://example.com');

  // Localização
  const titulo = page.getByRole('heading', {
    name: 'Example Domain'
  });

  // Validação
  await expect(titulo).toBeVisible();

  // Screenshot
  await page.screenshot({
    path: 'example.png'
  });

});
QA Note

Para memorizar os comandos, pense no fluxo: navegar → localizar → interagir → aguardar → validar . Na maioria dos testes E2E, esses cinco passos formam a base da automação com Playwright.
