CONCEITO / 16 STATE

Cookies e storage

Browser Context / Authentication State

Adicionar cookies

É possível adicionar cookies diretamente ao BrowserContext antes de executar as ações do teste. 

await context.addCookies([
  {
    name: 'session',
    value: 'abc123',
    domain: 'example.com',
    path: '/'
  }
]);

Consultar cookies

O método context.cookies() retorna os cookies disponíveis no contexto atual do navegador. 

const cookies = await context.cookies();

console.log(cookies);

Limpar cookies

O método clearCookies() remove os cookies armazenados no contexto do navegador. 

await context.clearCookies();

Trabalhando com localStorage

O localStorage permite armazenar dados diretamente no contexto da página. 

await page.goto('https://example.com');

await page.evaluate(() => {
  localStorage.setItem('token', 'abc123');
});

const token = await page.evaluate(() => {
  return localStorage.getItem('token');
});

console.log(token);

Trabalhando com sessionStorage

O sessionStorage permite armazenar dados associados à sessão da página. 

await page.evaluate(() => {
  sessionStorage.setItem('user', 'João');
});

const user = await page.evaluate(() => {
  return sessionStorage.getItem('user');
});

console.log(user);

Gerar estado de autenticação

O comando codegen pode ser utilizado para explorar uma aplicação e gerar interações automaticamente. 

npx playwright codegen https://example.com

Reutilizar estado de autenticação

Depois de obter um arquivo de estado, ele pode ser utilizado pelos testes através da configuração storageState. 

test.use({
  storageState: 'auth.json'
});

Salvar o estado durante a autenticação

Após realizar o login, o estado do contexto pode ser salvo em um arquivo para ser reutilizado posteriormente. 

import { test } from '@playwright/test';

test('login', async ({ page }) => {

  await page.goto('https://example.com/login');

  await page.getByLabel('Email').fill('user@example.com');

  await page.getByLabel('Senha').fill('123456');

  await page.getByRole('button', {
    name: 'Entrar'
  }).click();

  await page.context().storageState({
    path: 'auth.json'
  });

});

Exemplo completo

Depois que o estado de autenticação foi salvo, ele pode ser reutilizado em outros testes sem repetir o fluxo de login. 

import { test, expect } from '@playwright/test';

test.use({
  storageState: 'auth.json'
});

test('usuário autenticado', async ({ page }) => {

  await page.goto('https://example.com/dashboard');

  await expect(
    page.getByText('Dashboard')
  ).toBeVisible();

});
QA Note

O storageState é especialmente útil quando vários testes precisam iniciar já autenticados. Em vez de repetir o fluxo de login em cada teste, o estado da sessão pode ser salvo em um arquivo e reutilizado pelos testes. Cookies e storage também fazem parte do estado utilizado pelo contexto do navegador.
