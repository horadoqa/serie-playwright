Exemplo prático 
test('abrir nova aba', async ({ page }) => {

    await page.goto('https://example.com');

    const popupPromise =
        page.waitForEvent('popup');

    await page
        .getByRole('link', {
            name: 'Abrir relatório'
        })
        .click();

    const popup = await popupPromise;

    await popup.waitForLoadState('domcontentloaded');

    await expect(popup)
        .toHaveURL(/relatorio/);

    await expect(popup)
        .toHaveTitle(/Relatório/);

    await expect(
        popup.getByRole('heading', {
            name: 'Relatório'
        })
    ).toBeVisible();

});
Exemplo com múltiplas páginas 
test('trabalhar com múltiplas páginas', async ({ page }) => {

    await page.goto('https://example.com');

    const context = page.context();

    const newPagePromise =
        context.waitForEvent('page');

    const newPage =
        await context.newPage();

    await newPage.goto(
        'https://example.com/relatorio'
    );

    await newPagePromise;

    await expect(newPage)
        .toHaveURL(/relatorio/);

});
QA Note

Quando uma ação abre uma nova aba ou janela, utilize page.waitForEvent('popup') quando a nova página é aberta a partir da página atual. Para páginas criadas diretamente pelo contexto, utilize context.waitForEvent('page'). Depois de obter o objeto Page, você pode utilizar normalmente goto(), locator(), expect(), waitForLoadState() e outras APIs do Playwright.
