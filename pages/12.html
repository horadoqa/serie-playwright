Auto-waiting

O Playwright aguarda automaticamente que o elemento esteja em uma condição adequada antes de executar ações como click(), fill() e outras operações sobre locators. 

await page
.getByRole('button', {
    name: 'Salvar'
})
.click();

Aguardar uma condição

As assertions do Playwright também possuem espera automática. Elas podem aguardar até que a condição esperada seja satisfeita ou até que o timeout seja atingido. 

await expect(
page.getByText('Carregado')

).toBeVisible();

Aguardar mudança de URL

Use waitForURL() quando o teste precisar aguardar a navegação para uma URL específica. 

await page.waitForURL('**/dashboard');

Aguardar estado de carregamento

O método waitForLoadState() permite aguardar estados específicos do carregamento da página. 

await page.waitForLoadState('load');

await page.waitForLoadState('domcontentloaded');

await page.waitForLoadState('networkidle');

Aguardar uma resposta da API

waitForResponse() permite sincronizar o teste com uma resposta específica da aplicação. 

const responsePromise =
page.waitForResponse('**/api/users');

await page.getByRole('button', {
name: 'Carregar usuários'
}).click();

const response =
await responsePromise;

Aguardar uma requisição

waitForRequest() permite aguardar uma requisição específica realizada pela aplicação. 

const requestPromise =
page.waitForRequest('**/api/users');

await page.getByRole('button', {
name: 'Carregar usuários'
}).click();

const request =
await requestPromise;

Aguardar uma nova página

O evento popup pode ser aguardado quando uma ação abre uma nova página ou janela. 

const popupPromise =
page.waitForEvent('popup');

await page.getByRole('link', {
name: 'Abrir'
}).click();

const popup =
await popupPromise;

Aguardar elemento

O método waitFor() permite aguardar o elemento atingir uma condição de estado. 

await page
.getByRole('button', {
    name: 'Enviar'
})
.waitFor();

Configurar timeout

É possível definir um timeout específico para uma ação quando necessário. 

await page
.getByRole('button')
.click({
    timeout: 10000
});

Evite pausas fixas

waitForTimeout() interrompe a execução por um período fixo e geralmente não representa uma condição real da aplicação. 

// Evite quando possível

await page.waitForTimeout(3000);

Prefira aguardar o estado esperado

Em vez de aguardar uma quantidade fixa de tempo, aguarde diretamente o estado que indica que a operação terminou. 

await expect(
page.getByText('Processamento concluído')

).toBeVisible();

Exemplo prático

Neste exemplo, o teste aguarda o carregamento dos dados observando diretamente os elementos esperados na interface. 

test('aguardar carregamento', async ({ page }) => {

await page.goto('https://example.com');

await page.getByRole('button', {
    name: 'Carregar dados'
}).click();

await expect(
    page.getByText('Dados carregados')
).toBeVisible();

await expect(
    page.getByRole('table')
).toBeVisible();

});

Exemplo com API

Quando a ação depende de uma requisição específica, prepare a espera antes da ação para evitar perder o evento. 

test('aguardar resposta da API', async ({ page }) => {

await page.goto('https://example.com');

const responsePromise =
    page.waitForResponse('**/api/users');

await page.getByRole('button', {
    name: 'Carregar usuários'
}).click();

const response =
    await responsePromise;

expect(response.status()).toBe(200);

});
QA Note

Evite usar page.waitForTimeout() como estratégia principal de sincronização. Prefira aguardar uma condição real da aplicação, como um elemento ficar visível, uma URL mudar, uma resposta ser recebida ou um evento acontecer. O mecanismo de auto-waiting do Playwright já aguarda automaticamente várias condições antes de executar ações nos elementos.
