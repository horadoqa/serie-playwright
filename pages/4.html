CONCEITO / 04 LOCATORS

Locators

Finding Elements 
page.getByRole('button', {
    name: 'Login'
});

page.getByText('Bem-vindo');

page.getByLabel('Email');

page.getByPlaceholder('Digite seu email');

page.getByTestId('submit-button');
QA Note

Locators são a forma utilizada pelo Playwright para encontrar elementos na página. Sempre que possível, prefira estratégias que representem como o usuário realmente encontra ou utiliza o elemento.

Principais locators
Locator Quando utilizar
getByRole() Localiza elementos pelo papel acessível, como button, link, textbox, heading e checkbox.
getByText() Localiza elementos com base no texto visível apresentado ao usuário.
getByLabel() Localiza campos associados a um label, sendo especialmente útil em formulários.
getByPlaceholder() Localiza campos utilizando o texto apresentado no atributo placeholder.
getByTestId() Localiza elementos através de um identificador destinado aos testes, como data-testid.
locator() Permite criar locators utilizando seletores CSS ou outras estratégias quando necessário.
getByRole() 
await page.getByRole('button', {
    name: 'Login'
}).click();

await page.getByRole('link', {
    name: 'Produtos'
}).click();

await page.getByRole('heading', {
    name: 'Dashboard'
});

await page.getByRole('checkbox', {
    name: 'Aceito os termos'
});
getByLabel() 
await page.getByLabel('Email')
    .fill('user@example.com');

await page.getByLabel('Senha')
    .fill('123456');
getByText() 
await page.getByText('Bem-vindo')
    .click();

await expect(
    page.getByText(
        'Cadastro realizado com sucesso'
    )
).toBeVisible();
getByPlaceholder() 
await page.getByPlaceholder(
    'Digite seu email'
).fill('user@example.com');

await page.getByPlaceholder(
    'Pesquisar'
).fill('Playwright');
getByTestId() 
await page.getByTestId(
    'submit-button'
).click();

await expect(
    page.getByTestId('success-message')
).toBeVisible();
locator() 
await page.locator('#username')
    .fill('usuario');

await page.locator('.btn-primary')
    .click();

await page.locator(
    'input[name="email"]'
).fill('user@example.com');

Exemplos de escolha
Situação Locator recomendado
Botão "Salvar" getByRole('button', { name: 'Salvar' })
Campo Email getByLabel('Email')
Texto visível getByText('Bem-vindo')
Campo com placeholder getByPlaceholder('Pesquisar')
Elemento identificado para testes getByTestId('submit-button')
Elemento sem estratégia semântica adequada locator()
Boa prática 
// Preferir
await page.getByRole('button', {
    name: 'Salvar'
}).click();

// Em vez de
await page.locator('#btnSalvar').click();
Locator com filtro 
const produto = page
    .getByRole('listitem')
    .filter({
        hasText: 'Playwright'
    });

await produto
    .getByRole('button', {
        name: 'Comprar'
    })
    .click();
QA Note

Prefira locators que expressem a intenção do usuário. Em geral, estratégias baseadas em acessibilidade e elementos visíveis tornam os testes mais legíveis e menos dependentes da implementação interna da página. Use locator() quando as estratégias mais específicas não forem suficientes para identificar o elemento de maneira clara.
