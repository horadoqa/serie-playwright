Playwright

Screenshots

Como capturar imagens durante a execução dos testes utilizando o Playwright. Screenshots podem ser usados para evidências, investigação de falhas, documentação e análise visual da aplicação.

CONCEITO / 10 VISUAL / SCREENSHOT

Screenshots

Page Screenshot / Full Page / Element
Screenshot básico 
await page.screenshot({
path: 'screenshot.png'

});
Capturar página inteira 
await page.screenshot({
path: 'full.png',
fullPage: true

});
Capturar um elemento 
await page
.getByRole('main')
.screenshot({
    path: 'main.png'
});
Salvar como JPEG 
await page.screenshot({
path: 'screenshot.jpg',
type: 'jpeg',
quality: 80

});
Fundo transparente 
await page.screenshot({
path: 'screenshot.png',
omitBackground: true

});
Capturar após uma ação 
await page
.getByRole('button', { name: 'Salvar' })
.click();

await page.screenshot({
path: 'after-save.png'
});
Capturar elemento após uma ação 
await page
.getByRole('button', { name: 'Salvar' })
.click();

await page
.getByRole('main')
.screenshot({
path: 'main-after-save.png'
});
Exemplo prático 
import { test, expect } from '@playwright/test';

test('capturar evidência', async ({ page }) => {

await page.goto('https://example.com');

await page
    .getByRole('button', { name: 'Login' })
    .click();

await page
    .getByLabel('Email')
    .fill('user@example.com');

await page
    .getByLabel('Senha')
    .fill('123456');

await page
    .getByRole('button', { name: 'Entrar' })
    .click();

await expect(
    page.getByText('Login realizado com sucesso')
).toBeVisible();

await page.screenshot({
    path: 'login-success.png',
    fullPage: true
});

});
Screenshot automático no config 
import { defineConfig } from '@playwright/test';

export default defineConfig({

use: {
    screenshot: 'only-on-failure'
}

});
Outras opções de screenshot automático 
export default defineConfig({

use: {
    screenshot: 'on'
}

});
QA Note

Screenshots são especialmente úteis como evidência de execução e investigação de falhas. Para evitar arquivos desnecessários, uma estratégia comum é configurar screenshot: 'only-on-failure'. Para capturar uma página inteira manualmente, utilize fullPage: true. Também é possível capturar elementos específicos utilizando o método locator.screenshot().
