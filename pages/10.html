QA Note

Screenshots registram visualmente o estado da aplicação durante a execução do teste. Eles podem ser capturados manualmente com page.screenshot() ou automaticamente pelo Playwright utilizando a configuração screenshot.

Exemplo prático 
import { test, expect } from '@playwright/test';

test('capturar evidência de login', async ({ page }) => {

await page.goto('https://example.com');

await page
    .getByRole('button', {
        name: 'Login'
    })
    .click();

await page
    .getByLabel('Email')
    .fill('user@example.com');

await page
    .getByLabel('Senha')
    .fill('123456');

await page
    .getByRole('button', {
        name: 'Entrar'
    })
    .click();

await expect(
    page.getByText(
        'Login realizado com sucesso'
    )
).toBeVisible();

await page.screenshot({
    path: 'login-success.png',
    fullPage: true
});

});

export default defineConfig({

});
QA Note

Screenshots são especialmente úteis como evidência de execução e investigação de falhas. Para evitar arquivos desnecessários, uma estratégia comum é configurar screenshot: 'only-on-failure'. Para capturar uma página inteira manualmente, utilize fullPage: true. Também é possível capturar elementos específicos utilizando locator.screenshot().
