CONCEITO / 19 CONFIG

Configuração

playwright.config.ts

Configuração básica

O arquivo playwright.config.ts centraliza diversas configurações utilizadas durante a execução dos testes. 

import { defineConfig } from '@playwright/test';

export default defineConfig({
  testDir: './tests',

  use: {
    baseURL: 'https://example.com',
    headless: true,
    screenshot: 'only-on-failure',
    video: 'retain-on-failure',
    trace: 'on-first-retry'
  },

  retries: 2,

  workers: 4,

  reporter: 'html'
});

Diretório dos testes

A propriedade testDir define onde o Playwright deve procurar os arquivos de teste. 

export default defineConfig({
  testDir: './tests'
});

URL base

Com baseURL, os testes podem utilizar caminhos relativos em vez de repetir a URL completa da aplicação. 

use: {
  baseURL: 'https://example.com'
}

Com essa configuração, é possível navegar utilizando: 

await page.goto('/login');

await page.goto('/dashboard');

Headless

A propriedade headless controla se o navegador será executado com ou sem interface visual. 

use: {
  headless: true
}

Screenshots

A configuração screenshot determina quando screenshots devem ser capturados. 

use: {
  screenshot: 'only-on-failure'
}

Também é possível capturar screenshots sempre: 

use: {
  screenshot: 'on'
}

Gravação de vídeo

A propriedade video controla a gravação da execução dos testes. 

use: {
  video: 'retain-on-failure'
}

Trace

O Trace permite registrar informações detalhadas da execução, sendo especialmente útil para investigar falhas. 

use: {
  trace: 'on-first-retry'
}

Retries

A propriedade retries define quantas vezes um teste que falhou pode ser repetido. 

retries: 2

Workers

A propriedade workers controla a quantidade de workers utilizados para executar os testes em paralelo. 

workers: 4

Reporter

O reporter define como os resultados dos testes serão apresentados ou armazenados. 

reporter: 'html'

Configurar múltiplos projetos

A propriedade projects permite configurar diferentes browsers ou ambientes dentro da mesma suíte. 

import { defineConfig, devices } from '@playwright/test';

export default defineConfig({

  projects: [

    {
      name: 'chromium',
      use: {
        ...devices['Desktop Chrome']
      }
    },

    {
      name: 'firefox',
      use: {
        ...devices['Desktop Firefox']
      }
    },

    {
      name: 'webkit',
      use: {
        ...devices['Desktop Safari']
      }
    }

  ]

});

Timeout global

O timeout pode definir o tempo máximo permitido para a execução de cada teste. 

timeout: 30 * 1000

Timeout das assertions

A propriedade expect.timeout define o tempo máximo de espera das assertions. 

expect: {
  timeout: 5000
}

Exemplo completo

Um exemplo reunindo as principais configurações apresentadas: 

import { defineConfig, devices } from '@playwright/test';

export default defineConfig({

  testDir: './tests',

  timeout: 30 * 1000,

  expect: {
    timeout: 5000
  },

  retries: 2,

  workers: 4,

  reporter: 'html',

  use: {
    baseURL: 'https://example.com',

    headless: true,

    screenshot: 'only-on-failure',

    video: 'retain-on-failure',

    trace: 'on-first-retry'
  },

  projects: [

    {
      name: 'chromium',
      use: {
        ...devices['Desktop Chrome']
      }
    },

    {
      name: 'firefox',
      use: {
        ...devices['Desktop Firefox']
      }
    },

    {
      name: 'webkit',
      use: {
        ...devices['Desktop Safari']
      }
    }

  ]

});
QA Note

O arquivo playwright.config.ts deve concentrar as configurações compartilhadas da suíte. Isso evita repetir configurações em cada teste e facilita alterações de ambiente, browsers, evidências, retries, paralelismo e relatórios. Para projetos maiores, a configuração também pode ser organizada utilizando diferentes projects.
