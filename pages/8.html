QA Note

Um iframe cria um contexto de documento separado dentro da página. Para a maioria dos testes, utilize frameLocator() para localizar e interagir diretamente com elementos desse contexto. Quando for necessário acessar o objeto Frame, utilize recursos como page.frame() ou contentFrame().

Exemplo prático 
test('interagir com iframe', async ({ page }) => {

    await page.goto('https://example.com');

    const frame =
        page.frameLocator('#payment-frame');

    await frame
        .getByLabel('Número do cartão')
        .fill('4111111111111111');

    await frame
        .getByLabel('Nome')
        .fill('João da Silva');

    await frame
        .getByRole('button', {
            name: 'Pagar'
        })
        .click();

    await expect(
        frame.getByText('Pagamento aprovado')
    ).toBeVisible();

});
Exemplo usando contentFrame() 
test('acessar Frame diretamente', async ({ page }) => {

QA Note

Para a maioria dos testes que precisam interagir com elementos dentro de um iframe, prefira frameLocator(). Ele permite encadear locators diretamente dentro do frame e mantém o código simples. Quando for necessário trabalhar com o objeto Frame, utilize page.frame(), locator.contentFrame(), page.frames() ou page.mainFrame().
