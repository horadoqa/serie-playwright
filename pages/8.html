Playwright

Frames

Como acessar e interagir com elementos que estão dentro de iframes utilizando o Playwright. O frameLocator permite localizar elementos diretamente dentro de um frame de forma simples e segura, sem precisar recuperar manualmente o objeto Frame na maioria dos cenários.

CONCEITO / 08 FRAMES / IFRAME

Frames

FrameLocator / Frame / iframe
Localizar um iframe 
const frame =
    page.frameLocator('#payment-frame');
Interagir com elementos do frame 
const frame =
    page.frameLocator('#payment-frame');

await frame
    .getByRole('button', {
        name: 'Enviar'
    })
    .click();
Preencher campos dentro do frame 
const frame =
    page.frameLocator('#payment-frame');

await frame
    .getByLabel('Nome')
    .fill('João');
Localizar texto dentro do frame 
const frame =
    page.frameLocator('#payment-frame');

await expect(
    frame.getByText('Pagamento aprovado')
).toBeVisible();
Trabalhar com frames aninhados 
const nestedFrame =
    page
        .frameLocator('#iframe-principal')
        .frameLocator('#iframe-interno');

await nestedFrame
    .getByRole('button', {
        name: 'Confirmar'
    })
    .click();
Localizar iframe pelo atributo title 
const frame =
    page.frameLocator(
        'iframe[title="Pagamento"]'
    );

await frame
    .getByRole('button', {
        name: 'Pagar'
    })
    .click();
Localizar frame pela URL 
const frame =
    page.frame({
        url: /payment/
    });

await frame
    ?.getByRole('button', {
        name: 'Pagar'
    })
    .click();
Obter o objeto Frame 
const iframe =
    page.locator('#payment-frame');

const frame =
    await iframe.contentFrame();

await frame
    ?.getByLabel('Nome')
    .fill('João');
Listar frames da página 
const frames =
    page.frames();

for (const frame of frames) {

    console.log(
        frame.url()
    );

}
Acessar o frame principal 
const mainFrame =
    page.mainFrame();

console.log(
    mainFrame.url()
);
Exemplo prático 
test('interagir com iframe', async ({ page }) => {

    await page.goto('https://example.com');

    const frame =
        page.frameLocator('#payment-frame');

    await frame
        .getByLabel('Número do cartão')
        .fill('4111111111111111');

    await frame
        .getByLabel('Nome')
        .fill('João da Silva');

    await frame
        .getByRole('button', {
            name: 'Pagar'
        })
        .click();

    await expect(
        frame.getByText('Pagamento aprovado')
    ).toBeVisible();

});
Exemplo usando contentFrame() 
test('acessar Frame diretamente', async ({ page }) => {

    await page.goto('https://example.com');

    const iframe =
        page.locator('#payment-frame');

    const frame =
        await iframe.contentFrame();

    await frame
        ?.getByLabel('Nome')
        .fill('João');

});
QA Note

Para a maioria dos testes que precisam interagir com elementos dentro de um iframe, prefira frameLocator(). Ele permite encadear locators diretamente dentro do frame e mantém o código simples. Quando for necessário trabalhar com o objeto Frame, utilize métodos como page.frame(), locator.contentFrame(), page.frames() ou page.mainFrame().
