de API

Como interceptar, observar, modificar e controlar requisições de rede durante os testes. O Playwright permite trabalhar diretamente com o tráfego da aplicação para criar cenários controlados e validar diferentes comportamentos.

CONCEITO / 13 NETWORK

Interceptação de API

Network / Route / Request / Response

Interceptar uma requisição

O método page.route() permite interceptar requisições realizadas pela página e decidir como elas devem continuar. 

await page.route('**/api/users', async route => {

    await route.continue();

});

Observar uma requisição

O evento request permite acompanhar as requisições realizadas pela aplicação. 

page.on('request', request => {

    console.log(
        request.method(),
        request.url()
    );

});

Observar uma resposta

O evento response permite observar o status e a URL das respostas recebidas. 

page.on('response', response => {

    console.log(
        response.status(),
        response.url()
    );

});

Aguardar uma requisição

waitForRequest() aguarda uma requisição específica antes de continuar o teste. 

const requestPromise =
    page.waitForRequest('**/api/users');

await page.getByRole('button', {
    name: 'Carregar usuários'
}).click();

const request = await requestPromise;

Aguardar uma resposta

waitForResponse() permite aguardar uma resposta específica da aplicação. 

const responsePromise =
    page.waitForResponse('**/api/users');

await page.getByRole('button', {
    name: 'Carregar usuários'
}).click();

const response = await responsePromise;

Modificar uma requisição

É possível alterar headers ou outras propriedades da requisição antes de enviá-la ao servidor. 

await page.route('**/api/users', async route => {

    await route.continue({
        headers: {
            ...route.request().headers(),
            'x-test': 'playwright'
        }
    });

});

Bloquear uma requisição

O método route.abort() interrompe a requisição e pode ser utilizado para simular falhas ou bloquear determinados recursos. 

await page.route('**/analytics/**', async route => {

    await route.abort();

});

Responder diretamente

Com route.fulfill(), o teste pode fornecer uma resposta controlada sem depender do backend real. 

await page.route('**/api/users', async route => {

    await route.fulfill({
        status: 200,
        contentType: 'application/json',
        body: JSON.stringify([
            {
                id: 1,
                name: 'João'
            }
        ])
    });

});

Simular erro da API

Uma resposta de erro pode ser simulada para validar como a aplicação reage a falhas do backend. 

await page.route('**/api/users', async route => {

    await route.fulfill({
        status: 500,
        contentType: 'application/json',
        body: JSON.stringify({
            error: 'Internal Server Error'
        })
    });

});

Continuar requisição normalmente

route.continue() permite que a requisição siga normalmente para o servidor. 

await page.route('**/api/users', async route => {

    await route.continue();

});

Remover interceptação

page.unroute() remove uma rota previamente registrada na página. 

await page.unroute('**/api/users');

Exemplo prático

Neste exemplo, a resposta da API de usuários é interceptada e substituída por dados controlados pelo teste. 

test('interceptar usuários', async ({ page }) => {

    await page.route('**/api/users', async route => {

        await route.fulfill({
            status: 200,
            contentType: 'application/json',
            body: JSON.stringify([
                {
                    id: 1,
                    name: 'João'
                },
                {
                    id: 2,
                    name: 'Maria'
                }
            ])
        });

    });

    await page.goto('https://example.com');

    await page.getByRole('button', {
        name: 'Carregar usuários'
    }).click();

    await expect(
        page.getByText('João')
    ).toBeVisible();

    await expect(
        page.getByText('Maria')
    ).toBeVisible();

});
QA Note

Use page.route() quando precisar interceptar ou controlar o tráfego de rede. route.continue() permite seguir com a requisição original, route.fulfill() permite fornecer uma resposta controlada e route.abort() permite simular uma falha de rede. Para apenas observar o tráfego, request e response são úteis para acompanhar as chamadas realizadas pela aplicação.
