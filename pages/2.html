CONCEITO / 02 BASIC / TEST

Estrutura básica

Test / Page / Expect 
import { test, expect } from '@playwright/test';

test('meu teste', async ({ page }) => {
  await page.goto('https://example.com');

  await expect(page).toHaveTitle(/Example/);
});
QA Note

Um teste Playwright normalmente combina test para definir o caso de teste, page para interagir com a página e expect para validar o resultado esperado.

Elementos principais
Elemento Função
test Define um caso de teste e organiza o código que será executado durante o cenário.
expect Cria assertions para verificar se o comportamento observado corresponde ao resultado esperado.
page Representa uma página do navegador e permite navegar, localizar elementos e executar ações.
async Permite que a função do teste utilize operações assíncronas do Playwright.
await Aguarda a conclusão de uma operação assíncrona antes de continuar a execução do teste.
Importação 
import { test, expect } from '@playwright/test';
test() 
test('meu teste', async ({ page }) => {

  // passos do teste

});
page 
test('acessar página', async ({ page }) => {

  await page.goto('https://example.com');

});
expect() 
await expect(page)
  .toHaveTitle(/Example/);
Fluxo de execução 
test('meu teste', async ({ page }) => {

  // 1. Navegar
  await page.goto('https://example.com');

  // 2. Interagir
  await page.getByRole('button', {
    name: 'Continuar'
  }).click();

  // 3. Validar
  await expect(page)
    .toHaveTitle(/Example/);

});
Exemplo completo 
import { test, expect } from '@playwright/test';

test('realizar login', async ({ page }) => {

  await page.goto('https://example.com/login');

  await page.getByLabel('Email')
    .fill('user@example.com');

  await page.getByLabel('Senha')
    .fill('123456');

  await page.getByRole('button', {
    name: 'Entrar'
  }).click();

  await expect(page)
    .toHaveURL(/dashboard/);

  await expect(
    page.getByRole('heading', {
      name: 'Dashboard'
    })
  ).toBeVisible();

});
QA Note

Pense no teste como um fluxo: preparar → executar → validar. O test define o cenário, o page permite interagir com a aplicação e o expect representa aquilo que o teste precisa comprovar.
