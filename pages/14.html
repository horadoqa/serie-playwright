Mock
de API

Como substituir respostas reais da API por dados controlados durante os testes. O mock permite criar cenários previsíveis, testar diferentes respostas do backend e validar o comportamento da interface sem depender diretamente dos serviços externos.

Mock de API

Route / Fulfill / Mock Data

Mock básico 

await page.route(
'**/api/users',
async route => {

    await route.fulfill({
        status: 200,
        contentType: 'application/json',
        body: JSON.stringify([
            {
                id: 1,
                name: 'João'
            }
        ])
    });

}

);

Mock condicional 

await page.route(
'**/api/users',
async route => {

    const url = route.request().url();

    if (url.includes('empty=true')) {

        await route.fulfill({
            status: 200,
            contentType: 'application/json',
            body: JSON.stringify([])
        });

        return;
    }

    await route.fulfill({
        status: 200,
        contentType: 'application/json',

        body: JSON.stringify([
            {
                id: 1,
                name: 'João'
            }
        ])
    });

}

);

Modificar resposta real 

await page.route(
'**/api/users',
async route => {

    const response =
        await route.fetch();

    const json =
        await response.json();

    json.users.push({
        id: 99,
        name: 'Usuário Mock'
    });

    await route.fulfill({
        response,
        json
    });

}

);

Exemplo prático 

test('exibir usuários mockados', async ({ page }) => {

await page.route(
    '**/api/users',
    async route => {

        await route.fulfill({
            status: 200,
            contentType: 'application/json',

            body: JSON.stringify([
                {
                    id: 1,
                    name: 'João'
                },
                {
                    id: 2,
                    name: 'Maria'
                }
            ])
        });

    }
);

await page.goto('https://example.com');

await page.getByRole('button', {
    name: 'Carregar usuários'
}).click();

await expect(
    page.getByText('João')
).toBeVisible();

await expect(
    page.getByText('Maria')
).toBeVisible();

});
QA Note

O mock permite controlar completamente o cenário de teste. Você pode simular sucesso, erro, lista vazia, dados específicos e respostas inesperadas sem precisar alterar o backend. Para alterar apenas parte de uma resposta real, utilize route.fetch() e depois route.fulfill() com os dados modificados.
