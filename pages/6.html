Expect & Assertions

Test / Validate / Expect
Exemplo básico 
await expect(page)
.toHaveTitle('Página inicial');

await expect(page)
.toHaveURL(/dashboard/);

await expect(
page.getByText('Sucesso')
).toBeVisible();
QA Note

Assertions representam aquilo que o teste espera encontrar como resultado. O expect() recebe o valor ou elemento que será validado, enquanto o matcher define a condição esperada, como toBeVisible(), toHaveText() ou toHaveURL().

Principais assertions
Assertion Função
toHaveTitle() Verifica o título atual da página.
toHaveURL() Verifica se a URL atual corresponde ao valor ou padrão esperado.
toBeVisible() Verifica se o elemento está visível.
toBeEnabled() Verifica se o elemento está habilitado.
toBeDisabled() Verifica se o elemento está desabilitado.
toHaveText() Verifica o texto de um elemento.
toHaveValue() Verifica o valor atual de um campo.
toBeChecked() Verifica se um checkbox ou radio está marcado.
toHaveCount() Verifica a quantidade de elementos encontrados.

Exemplo completo 
import { test, expect } from '@playwright/test';

test('validar login', async ({ page }) => {

await page.goto(
    'https://example.com/login'
);

await page.getByLabel('Email')
    .fill('user@example.com');

await page.getByLabel('Senha')
    .fill('123456');

await page.getByRole('button', {
    name: 'Entrar'
}).click();

await expect(page)
    .toHaveURL(/dashboard/);

await expect(
    page.getByRole('heading', {
        name: 'Dashboard'
    })
).toBeVisible();

});
Boas práticas 
// Validar o resultado que realmente importa

await expect(page)
.toHaveURL(/dashboard/);

// Validar aquilo que o usuário consegue observar

await expect(
page.getByRole('heading', {
name: 'Dashboard'
})
).toBeVisible();

// Validar dados importantes da API

expect(response.status())
.toBe(200);

expect(body.authorization)
.toEqual(
expect.stringContaining('Bearer ')
);
QA Note

Uma boa assertion deve validar o resultado que realmente importa para o teste. Em UI, valide aquilo que o usuário consegue observar, como URL, texto, visibilidade e estado dos elementos. Em API, valide também status HTTP, mensagens, IDs, tokens e dados retornados.
