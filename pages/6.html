CONCEITO / 06 ASSERTIONS

Expect & Assertions

Test / Validate / Expect
Exemplo básico 
await expect(page)
.toHaveTitle('Página inicial');

await expect(page)
.toHaveURL(/dashboard/);

await expect(
page.getByText('Sucesso')
).toBeVisible();
QA Note

Assertions representam aquilo que o teste espera encontrar como resultado. O expect() recebe o elemento ou valor que será validado, enquanto o matcher, como toBeVisible(), toHaveText() ou toHaveURL(), define a condição esperada.

Principais assertions
Assertion Função
toHaveTitle() Verifica o título atual da página.
toHaveURL() Verifica se a URL atual corresponde ao valor ou padrão esperado.
toBeVisible() Verifica se o elemento está visível para o usuário.
toBeEnabled() Verifica se o elemento está habilitado para interação.
toBeDisabled() Verifica se o elemento está desabilitado.
toHaveText() Verifica o texto de um elemento.
toHaveCount() Verifica a quantidade de elementos encontrados por um locator.
toHaveTitle() 
await expect(page)
.toHaveTitle('Página inicial');

await expect(page)
.toHaveTitle(/Página/);
toHaveURL() 
await expect(page)
.toHaveURL('https://example.com/dashboard');

await expect(page)
.toHaveURL(/dashboard/);
toBeVisible() 
await expect(
page.getByText('Sucesso')

).toBeVisible();

await expect(
page.getByRole('heading', {
name: 'Dashboard'
})
).toBeVisible();
toBeEnabled() / toBeDisabled() 
await expect(
page.getByRole('button', {
    name: 'Enviar'
})

).toBeEnabled();

await expect(
page.getByRole('button', {
name: 'Enviar'
})
).toBeDisabled();
toHaveText() 
await expect(
page.getByRole('heading')

).toHaveText('Dashboard');

await expect(
page.getByTestId('mensagem')
).toHaveText('Olá, João');
toHaveCount() 
await expect(
page.locator('.item')

).toHaveCount(5);

await expect(
page.getByRole('listitem')
).toHaveCount(3);
Assertions negativas 
await expect(
page.getByText('Erro')

).not.toBeVisible();

await expect(
page.getByRole('button', {
name: 'Enviar'
})
).not.toBeDisabled();
Validar estados de elementos 
await expect(
page.getByRole('checkbox', {
    name: 'Aceitar termos'
})

).toBeChecked();

await expect(
page.getByRole('textbox', {
name: 'Email'
})
).toHaveValue('user@example.com');
Fluxo completo 
import { test, expect } from '@playwright/test';

test('validar login', async ({ page }) => {

await page.goto('https://example.com/login');

await page.getByLabel('Email')
    .fill('user@example.com');

await page.getByLabel('Senha')
    .fill('123456');

await page.getByRole('button', {
    name: 'Entrar'
}).click();

await expect(page)
    .toHaveURL(/dashboard/);

await expect(
    page.getByRole('heading', {
        name: 'Dashboard'
    })
).toBeVisible();

});
QA Note

Prefira assertions que representem o comportamento que realmente precisa ser validado. Em vez de verificar detalhes internos da implementação, valide aquilo que o usuário deveria observar, como URL, texto, visibilidade, estado dos elementos e quantidade de elementos.
