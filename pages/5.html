QA Note

As ações do Playwright são realizadas principalmente através de locators. Depois de localizar um elemento, podemos executar ações como click(), fill(), press(), check(), uncheck(), selectOption() e setInputFiles().

Principais ações
Ação Função
click() Clica em um elemento da página.
fill() Preenche um campo de entrada com um determinado valor.
press() Pressiona uma tecla ou combinação de teclas em um elemento.
check() Marca um checkbox ou radio button.
uncheck() Desmarca um checkbox.
selectOption() Seleciona uma opção em um elemento HTML <select>.
setInputFiles() Define um ou mais arquivos em um campo de upload.

Exemplo completo 
import { test, expect } from '@playwright/test';

test('preencher formulário', async ({ page }) => {

    await page.goto('https://example.com');

    await page.getByLabel('Nome')
        .fill('João');

    await page.getByLabel('Email')
        .fill('joao@example.com');

    await page.getByLabel('Estado')
        .selectOption('sp');

    await page.getByRole('checkbox', {
        name: 'Aceito os termos'
    }).check();

    await page.getByRole('button', {
        name: 'Enviar'
    }).click();

    await expect(
        page.getByText(
            'Cadastro realizado com sucesso'
        )
    ).toBeVisible();

});
Boas práticas 
// Localizar + executar ação

const botaoSalvar = page.getByRole('button', {
    name: 'Salvar'
});

await botaoSalvar.click();


// Preencher campos com locator semântico

await page.getByLabel('Email')
    .fill('qa@example.com');


// Validar o resultado da ação

await expect(
    page.getByText('Salvo com sucesso')
).toBeVisible();
QA Note

Um bom teste normalmente segue uma sequência simples: localizar → agir → validar. O locator identifica o elemento, a ação modifica ou interage com a aplicação e o expect() verifica se o comportamento esperado realmente aconteceu.
