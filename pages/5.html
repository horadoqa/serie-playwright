QA Note

As ações do Playwright são realizadas principalmente através de locators. Depois de localizar um elemento, você pode executar ações como click(), fill(), press(), check(), uncheck(), selectOption() e setInputFiles().

Principais ações
Ação Função
click() Clica em um elemento da página.
fill() Preenche um campo de entrada com um determinado valor.
press() Pressiona uma tecla ou combinação de teclas em um elemento.
check() Marca um checkbox ou radio button.
uncheck() Desmarca um checkbox.
selectOption() Seleciona uma opção em um elemento HTML <select>.
setInputFiles() Define um ou mais arquivos em um campo de upload.
click() 
await page.getByRole('button', {

name: 'Salvar'
}).click();

await page.getByRole('link', {
name: 'Produtos'
}).click();

await page.getByText('Continuar').click();
fill() 
await page.getByLabel('Nome')

.fill('João');

await page.getByLabel('Email')
.fill('joao@example.com');

await page.getByLabel('Senha')
.fill('123456');
press() 
await page.getByLabel('Nome')

.press('Enter');

await page.getByPlaceholder('Pesquisar')
.press('Enter');

await page.getByLabel('Campo')
.press('Control+A');
check() / uncheck() 
await page.getByRole('checkbox', {

name: 'Aceito os termos'
}).check();

await page.getByRole('checkbox', {
name: 'Aceito os termos'
}).uncheck();
selectOption() 
await page.getByLabel('Estado')

.selectOption('sp');

await page.getByLabel('Estado')
.selectOption({
label: 'São Paulo'
});
setInputFiles() 
await page.getByLabel('Arquivo')

.setInputFiles('arquivo.pdf');
Fluxo completo 
import { test, expect } from '@playwright/test';

test('preencher formulário', async ({ page }) => {

await page.goto('https://example.com');

await page.getByLabel('Nome')
.fill('João');

await page.getByLabel('Email')
.fill('joao@example.com');

await page.getByLabel('Estado')
.selectOption('sp');

await page.getByRole('checkbox', {
name: 'Aceito os termos'
}).check();

await page.getByRole('button', {
name: 'Enviar'
}).click();

await expect(
page.getByText('Cadastro realizado com sucesso')
).toBeVisible();

});
QA Note

Prefira realizar ações através de locators estáveis e semânticos. Por exemplo, utilize getByRole(), getByLabel(), getByText() ou getByTestId() quando forem apropriados para o elemento. Evite depender de seletores frágeis quando existir uma forma mais estável de identificar o elemento.
