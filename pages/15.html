Requisições HTTP

GET / POST / PUT / PATCH / DELETE

GET — consultar dados 

test('consultar usuários', async ({ request }) => {

const response =
await request.get('/api/users');

expect(response.ok()).toBeTruthy();

const data =
await response.json();

console.log(data);

});

Validar status da resposta 

const response =
await request.get('/api/users');

expect(response.status()).toBe(200);

expect(response.ok()).toBeTruthy();

Ler resposta JSON

await request.get('/api/users');

await response.json();

POST — criar recurso 

const response =
await request.post('/api/users', {

    data: {
        name: 'João',
        email: 'joao@example.com'
    }

});

expect(response.status()).toBe(201);

APIRequestContext 

import {
test,
expect,
request

} from '@playwright/test';

test('API', async () => {

const apiContext =
    await request.newContext({
        baseURL: 'https://example.com'
    });

const response =
    await apiContext.get('/api/users');

expect(response.ok()).toBeTruthy();

await apiContext.dispose();

});

Exemplo prático 

test('criar e validar usuário', async ({ request }) => {

const createResponse =
    await request.post('/api/users', {

        data: {
            name: 'João',
            email: 'joao@example.com'
        }

    });

expect(
    createResponse.status()
).toBe(201);

const createdUser =
    await createResponse.json();

expect(
    createdUser.name
).toBe('João');

const getResponse =
    await request.get(
        `/api/users/${createdUser.id}`
    );

expect(
    getResponse.status()
).toBe(200);

const user =
    await getResponse.json();

expect(
    user.email
).toBe('joao@example.com');

});
QA Note

O objeto request permite testar APIs sem precisar abrir uma página no navegador. Utilize GET para consultas, POST para criação, PUT/PATCH para atualizações e DELETE para remoção. Valide não apenas o status HTTP, mas também o corpo da resposta, headers e os dados retornados pela API.
