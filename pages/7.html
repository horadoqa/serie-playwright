QA Note

Locators avançados permitem refinar uma seleção quando existem vários elementos semelhantes na página. O Playwright oferece recursos como filter(), has, first(), last(), nth(), and() e or() para tornar a localização mais específica.

Filtrar por texto 
const salvar =
    page
        .getByRole('button')
        .filter({
            hasText: 'Salvar'
        });

await salvar.click();
Filtrar por elemento interno 
const card =
    page
        .locator('.card')
        .filter({
            has: page.getByRole('heading', {
                name: 'Notebook'
            })
        });

await expect(card).toBeVisible();

Boas práticas 
// Prefira locators semânticos

page.getByRole('button', {
    name: 'Salvar'
});

// Use filter() quando houver
// elementos semelhantes

page
    .locator('.card')
    .filter({
        hasText: 'Notebook'
    });

// Use has quando o elemento
// depender de conteúdo interno

page
    .locator('.card')
    .filter({
        has: page.getByRole('heading', {
            name: 'Notebook'
        })
    });

// Use first(), last() e nth()
// quando a posição fizer sentido

page.locator('.item').first();

page.locator('.item').last();

page.locator('.item').nth(2);
QA Note

Locators avançados devem ser utilizados para tornar a seleção mais precisa, e não apenas para contornar um locator mal definido. Comece por locators semânticos como getByRole(), getByLabel() e getByText(). Quando houver elementos semelhantes, utilize filter() e has para restringir o contexto. Use first(), last() e nth() quando a posição for realmente relevante para o cenário. Para combinar alternativas ou condições, utilize or() e and().
