Playwright

Locators
avançados

Técnicas para combinar, filtrar e selecionar elementos de forma mais precisa utilizando os locators do Playwright. Esses recursos são úteis quando um locator simples não é suficiente para identificar o elemento desejado.

CONCEITO / 07 ADVANCED / LOCATORS

Locators avançados

Filter / Has / First / Last / Nth / And / Or
Filtrar por texto 
const salvar =
    page
        .getByRole('button')
        .filter({
            hasText: 'Salvar'
        });

await salvar.click();
Filtrar por elemento interno 
const card =
    page
        .locator('.card')
        .filter({
            has: page.getByRole('heading', {
                name: 'Notebook'
            })
        });

await expect(card).toBeVisible();
Filtrar usando expressão regular 
const produto =
    page
        .locator('.card')
        .filter({
            hasText: /Notebook/i
        });

await expect(produto).toBeVisible();
Primeiro elemento 
const primeiro =
    page.locator('.item').first();

await primeiro.click();
Último elemento 
const ultimo =
    page.locator('.item').last();

await ultimo.click();
Elemento por índice 
const terceiro =
    page.locator('.item').nth(2);

await terceiro.click();
Contar elementos encontrados 
const quantidade =
    await page.locator('.item').count();

console.log(quantidade);
Combinar locators com AND 
const botao =
    page
        .getByRole('button')
        .and(
            page.getByText('Salvar')
        );

await botao.click();
Trabalhar com alternativas usando OR 
const mensagem =
    page
        .getByText('Sucesso')
        .or(page.getByText('Concluído'));

await expect(mensagem.first())
    .toBeVisible();
Filtrar e localizar um elemento interno 
const produto =
    page
        .locator('.card')
        .filter({
            hasText: 'Notebook'
        });

await produto
    .getByRole('button', {
        name: 'Comprar'
    })
    .click();
Exemplo prático 
test('selecionar produto específico', async ({ page }) => {

    await page.goto('https://example.com');

    const produto =
        page
            .locator('.card')
            .filter({
                hasText: 'Notebook'
            });

    await expect(produto)
        .toBeVisible();

    await produto
        .getByRole('button', {
            name: 'Comprar'
        })
        .click();

    await expect(
        page.getByText('Produto adicionado')
    ).toBeVisible();

});
Exemplo usando has 
test('localizar card pelo conteúdo interno', async ({ page }) => {

    const produto =
        page
            .locator('.card')
            .filter({
                has: page.getByRole('heading', {
                    name: 'Notebook'
                })
            });

    await expect(produto)
        .toBeVisible();

    await produto
        .getByRole('button', {
            name: 'Comprar'
        })
        .click();

});
QA Note

Locators avançados são úteis quando existem vários elementos semelhantes na página. Prefira começar com locators semânticos como getByRole, getByLabel e getByText. Quando necessário, utilize filter() para restringir a seleção, has para procurar conteúdo interno, first(), last() e nth() para selecionar uma posição específica, e and() ou or() para combinar locators.
