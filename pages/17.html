Debug

Debugging / Inspection / Codegen

Executar no modo debug

O modo --debug inicia os testes com recursos de depuração que permitem acompanhar a execução passo a passo. 

npx playwright test --debug

Executar com o navegador visível

O parâmetro --headed executa o teste exibindo a janela do navegador. 

npx playwright test --headed

Utilizar o UI Mode

O --ui abre a interface gráfica do Playwright, permitindo executar, acompanhar e investigar os testes de forma interativa. 

npx playwright test --ui

Pausar a execução

O método page.pause() interrompe a execução naquele ponto para permitir a inspeção da página e dos elementos. 

import { test } from '@playwright/test';


test('debug do formulário', async ({ page }) => {

await page.goto('https://example.com');

await page.pause();

await page.getByRole('button', {
name: 'Login'
}).click();

});

Gerar código automaticamente

O codegen abre o navegador e permite realizar ações manualmente enquanto o Playwright gera o código correspondente às interações. 

npx playwright codegen https://example.com

Codegen com projeto específico

Também é possível utilizar o codegen com configurações específicas do projeto. 

npx playwright codegen --browser chromium https://example.com

Utilizar o Playwright Inspector

O Inspector permite acompanhar a execução, selecionar elementos, visualizar locators e avançar pelas etapas do teste. 

PWDEBUG=1 npx playwright test

Depurar um teste específico

Para investigar uma falha específica, combine o modo debug com o arquivo ou teste que deseja executar. 

npx playwright test tests/login.spec.ts --debug

Depurar pelo nome do teste 

npx playwright test -g "login" --debug

Investigação com Trace

O Trace permite analisar posteriormente uma execução, incluindo ações realizadas, screenshots, informações de rede e outros detalhes da execução. 

npx playwright show-trace trace.zip
QA Note

Para investigar uma falha rapidamente, uma sequência prática é começar com --headed ou --debug. Quando for necessário acompanhar visualmente a execução, utilize o --ui ou page.pause(). Para investigar uma execução já concluída, o Trace Viewer pode fornecer informações adicionais sobre as etapas realizadas.
